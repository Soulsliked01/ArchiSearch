# ArchiSearch
App locale python permettant l'ajout de bâtiments d'architecture de plusieurs types.

# Fonctionnement
Sur un pc ayant python
double cliquer *build.bat*
--> un répertoire dist se créé avec un dossier ArchiSearch
--> zipper le
--> envoyer à son collège / camarade
--> Dézipper le dossier, puis ouvrir et lancer le .exe
--> une fenêtre noire s'ouvre, c'est normal c'est l'application
--> le browser ouvre l'app avec des mocks data
--> tout ajout/supression sur le site modifiera la db qui sera présente dans le dossier ArchiSearch

N'hésiter pas à l'optimiser l'HTML et le CSS sont mis en forme par mes soins et retravaillé avec Claude AI 
Le programme python gérant les DB est fait partiellement par IA pour la gestion écriture / lecture sur la db.
